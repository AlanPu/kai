## 已知文档缺口

读代码时注意这几处，**别被文档误导**：

- `开发计划.md:73-82` 的模块表列了 `app/services/report.py` 和 `app/api/routes.py`
  —— 这两个文件不存在（报告逻辑在 `server.py:_build_report`，路由全在 `server.py`）
- `.env.example` 里有 5 个键 `config.py` 根本不读：`AZURE_SPEECH_KEY`、
  `AZURE_SPEECH_REGION`（全仓库零命中）、以及 4 个代理变量
  （文本链路在 `llm.py:59-62` 主动清空代理直连）
- 反过来，`VOICEPRINT_PATH`、`VOICEPRINT_MODEL`、`VOICEPRINTS_DIR`、`DB_PATH`、
  `PROFILES_DIR` 这 5 个 `config.py` 真读的变量没写进 `.env.example`
- 阶段 8–19（改按 C 键、修断线等）**没有对应的测试文件**，
  新增的测试都并进了 `test_stage7_users.py`
- `db.py` 的迁移机制（`_apply_migrations`，只执行过一次）零测试覆盖

## 代码里没写但容易踩的地方

- 上行音频是**裸二进制帧**，下行音频是 **JSON + base64**，方向不对称
- `audio.py` 里的 `IN_BLOCK`/`BLOCK_MS` 在网页路径上**从未被引用**，
  那是给桌面 Python 客户端的常量
- WS 链路备课**不注入画像**，只有 HTTP `/api/prepare` 注入
  （`server.py:622` vs `server.py:445`）——网页点"开始"走的正是前者
- 服务端 `error` 字段在建连失败时是**字符串**、运行时是 **dict**，
  前端靠一个三元表达式隐式兼容
