# 英语口语陪练 — 使用说明

> ⚠️ **当前状态：语音额度已用完，暂时无法进行语音练习。**
> 需要到阿里云百炼控制台充值、或关掉「仅使用免费额度」。
> 详见 [待处理-额度.md](待处理-额度.md)。
> 文本能力（规划/纠错）不受影响，仍可正常使用。

## 启动

```bash
cd .
.venv/bin/python -m app            # 默认 http://localhost:8000
```

浏览器打开提示的地址即可。

> 麦克风只在 `localhost` 或 `https` 下可用。
> 想用手机/平板连，需要配 HTTPS 证书（见文末）。

## 一次练习的流程

### 1. 给素材（四种都行）

| 类型 | 例子 |
|---|---|
| 主题 | `远程办公` |
| 一段话 | 两三句中文或英文 |
| 一篇文章 | 直接粘贴，越长越好 |
| 一个网址 | 贴链接，会自动抓正文 |

四种按你每次的心情临时决定就行 —— 程序会自动判断类型。

选好后点「开始」，它会先分析内容、**预先生成话题计划**
（你能在开始前看到它打算聊什么），然后 AI 主动开场。

### 2. 聊

- AI 会**主动引导**，每轮用开放式问题把话头递回给你
- 你说得越多，它越少抢话
- 右侧栏会**实时显示**语法/用词纠正，不会打断你说话
- AI 也会在你说完一段后**自然带一句**提醒（不会反复打断）

### 3. 中途要离开

点「暂停」。暂停期间不计时、麦克风静音，回来点「继续」。
**不要**直接走开 —— 超过 5 分钟服务端会关闭会话。

### 4. 结束

30 分钟自动结束，或随时点「结束」。会给你一份报告：

- 用时、发言轮数、字数、**你说话占比**
- 本次的纠错清单
- 费用估算

## 它会越来越了解你

每次对话后，程序会从你的发言里提取信息存进个人画像
（职业、城市、兴趣、常犯的语言错误等）。

下次开始时，AI 已经知道你是谁 —— 开场白会不一样。

- 点顶部「我的画像」可以查看它记住了什么
- 可以导出成 Markdown

---

## 几个如实说明

- **费用是估算值**。Realtime 音频可能按时长计费，
  给的数字仅供参考。单次 30 分钟在**亚元级**。
- **声纹不是安全验证**。它的作用是避免 AI 把自己的声音
  当成你在说话。换麦克风或环境会退化，感冒时基本失效。
  （也可以在设置里关掉。）
- **发音纠正**只针对特别明显的错误（比如转写出来就是错词），
  轻微口音问题不会纠正 —— 这是刻意的，避免打断你。

## 命令行工具（不消耗语音费用）

想单独看看计划或纠错效果：

```bash
.venv/bin/python -m app.cli plan "远程办公"
.venv/bin/python -m app.cli check "I go to park yesterday."
```

## 手机上用

需要 HTTPS（浏览器对局域网 IP 的 HTTP 页面禁用麦克风）：

```bash
.venv/bin/python scripts/make_cert.py
.venv/bin/python -m app --host 0.0.0.0 \
    --ssl-keyfile key.pem --ssl-certfile cert.pem
```

然后手机访问 `https://<你电脑的IP>:8000`。
浏览器会警告证书不受信任，选择「继续访问」即可
（自签证书的正常现象）。

⚠️ 手机浏览器**尚未实际测试过**，如果有问题请告诉我。
