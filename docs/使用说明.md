# 英语口语陪练 — 使用说明

## 启动

```bash
cd kai
./start.sh                 # 默认 http://127.0.0.1:8000
```

浏览器打开提示的地址即可。

脚本会自动**先停掉旧的进程**再启动 —— 这一点很重要：如果直接重复启动，
新进程会因为端口被占用而失败，但旧进程还在响应，表现为「改了东西却没生效」。
脚本还会在启动后做一次健康检查，起不来会直接告诉你，并打印日志。

### 常用命令

```bash
./start.sh --status        # 看是否在运行、健康检查是否正常
./start.sh --stop          # 停止
./start.sh --logs          # 实时看日志（出错先看这个）
./start.sh --help          # 全部用法
```

日志在 `data/logs/server.log`。每次启动都会打印**实际生效的模型和参数**，
一眼就能核对配置对不对。

### 其他启动方式

```bash
./start.sh --port 8001     # 换端口
./start.sh --reload        # 改代码自动重启（开发用）
./start.sh --ssl           # 手机/平板用，脚本会打印手机访问地址
```

不想用脚本也可以手敲（等价）：

```bash
pkill -f run.py && .venv/bin/python run.py
```

> 麦克风只在 `localhost` 或 `https` 下可用。
> 想用手机/平板连，需要配 HTTPS 证书（见文末）。

## 多人共用一台电脑

页面左上角是**用户切换器**。每个用户有各自的：

- 声纹（用于"只回应我的声音"）
- 个人画像（兴趣、背景、反复出错的点）
- 练习记录和统计

互不干扰 —— 甲练完切到乙，乙看到的画像和历史是乙自己的。

### 第一次用

打开页面会让你**新建一个用户**（起个名字即可），
然后自动引导**录入声纹**：跟读 5 句话，每句读完点「读完了」。

- 至少录 3 句才能保存，录满 5 句更稳
- 每句读完会当场告诉你好不好；不好就重录这一句
- 全部读完后显示声纹质量（好 / 一般 / 偏差）

### 换人用

点左上角用户名 → 选另一个用户 → 关掉弹窗即可。
选择记在浏览器里，下次打开还是这个人。

### 声纹不准了怎么办

几种情形和对应做法：

| 情形 | 做法 |
|---|---|
| 换麦克风 / 换房间后认不出来 | 点用户名 → 重新录入声纹 |
| 电脑外放，把旁人说话也当成了你 | 同上，重录；或勾掉「只回应我的声音」 |
| 只想重录声纹，保留画像和历史 | 同上 —— 重录只覆盖声纹，不动其他数据 |
| 想彻底清掉某个人的全部数据 | 点用户名 → 那一行的「删除」（不可恢复） |

> **如实说明**：声纹不是密码级的安全措施。
> 它靠音色相似度判断，会有**刚开始几秒的误放行**，
> 换环境后准确率下降，感冒时也可能认不出你。
> 它的用途是"过滤掉旁人和电视声"，不是身份验证。

## 一次练习的流程

### 1. 给素材（四种都行）

| 类型 | 例子 |
|---|---|
| 主题 | `远程办公` |
| 一段话 | 两三句中文或英文 |
| 一篇文章 | 直接粘贴，越长越好 |
| 一个网址 | 贴链接，会自动抓正文 |

四种按你每次的心情临时决定就行 —— 程序会自动判断类型。

选好后点「开始」，它会先分析内容、**预先生成话题计划**
（你能在开始前看到它打算聊什么），然后 AI 主动开场。

### 2. 聊

- AI 会**主动引导**，每轮用开放式问题把话头递回给你
- 你说得越多，它越少抢话
- 右侧栏会**实时显示**语法/用词纠正，不会打断你说话
- AI 也会在你说完一段后**自然带一句**提醒（不会反复打断）

### 3. 中途要离开

点「暂停」。暂停期间不计时、麦克风静音，回来点「继续」。
**不要**直接走开 —— 超过 5 分钟服务端会关闭会话。

### 4. 结束

30 分钟自动结束，或随时点「结束」。会给你一份报告：

- 用时、发言轮数、字数、**你说话占比**
- 本次的纠错清单
- 费用估算

## 它会越来越了解你

每次对话后，程序会从你的发言里提取信息存进个人画像
（职业、城市、兴趣、常犯的语言错误等）。

下次开始时，AI 已经知道你是谁 —— 开场白会不一样。

- 点顶部「我的画像」可以查看它记住了什么
- 可以导出成 Markdown

---

## 几个如实说明

- **费用是估算值**。Realtime 音频可能按时长计费，
  给的数字仅供参考。单次 30 分钟在**亚元级**。
- **声纹不是安全验证**。它的作用是避免 AI 把旁人的声音
  当成你在说话。换麦克风或环境会退化，感冒时基本失效。
  好在随时可以重录（见上文「多人共用一台电脑」）。
- **声纹的"质量分"只衡量这次录得稳不稳**，
  不是"能不能认出你"。录入时现场没有别人做对比，
  程序没法测区分度。所以显示"一般"只代表
  "这几句读得不太一致，可能不够稳"，不代表一定不能用。
- **发音纠正**只针对特别明显的错误（比如转写出来就是错词），
  轻微口音问题不会纠正 —— 这是刻意的，避免打断你。

## 手机上用

需要 HTTPS（浏览器对局域网 IP 的 HTTP 页面禁用麦克风）：

```bash
.venv/bin/python scripts/make_cert.py   # 生成证书（会自动带上局域网 IP）
./start.sh --ssl                        # 脚本会打印手机该访问的地址
```

证书脚本会打印形如 `https://192.168.x.x:8000` 的地址，
`./start.sh --ssl` 启动后也会再显示一次，照着在手机上打开即可。
浏览器会警告证书不受信任，点「高级」→「继续前往」
（自签证书的正常现象）。

> 证书路径默认是 `certs/cert.pem` 和 `certs/key.pem`，
> 想放别处用 `--ssl-certfile` / `--ssl-keyfile` 指定。

⚠️ **电脑上的浏览器已验证可用**（`https://0.0.0.0` 绑定的
本地和局域网地址都能访问并通过健康检查）。
**手机端尚未实机测试过** —— 我没有可用的手机环境，
麦克风权限、iOS Safari 的兼容性还需要你实际试一下。
